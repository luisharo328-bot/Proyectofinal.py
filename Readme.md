# Calculadora  de IMC _ Proyecto final

## Descripción del programa
Este programa pide nombre, apellido, edad, estatura y peso.
Calcula  el índice de Masa corporal (IMC) con la fórmula peso / (estatura ** 2 )
y muestra al cliente sí se encuentra por debajo del peso, en peso normal o por encima del peso.
El programa tien validaciones para que no falle:
- Sí se deja un campo vacio muestra "Error, no puede quedar vacio y vuelve a pedirlo.
- Sí se escriben letras en edad, peso o estatura, muestra "Error, debe ingresar un numero válido" y vuelve a pedirlo, no se cierra 

## Instrucciones de ejecucuión 
1. Tener Python instalado.
2. Abrir la carpeta del proyecto
3. Ejecutar en la terminal:python Formulario.py
4. Seguir lo que pide en pantalla: nombre, apellido, edad, edad, estatura, y peso.
